# 🎓 Student Placement Prediction

A Machine Learning web application that predicts whether a student is likely to be placed based on academic performance, skills, and other relevant factors.

## 📌 Project Overview

**Student Placement Prediction** is a Machine Learning project developed to demonstrate how data analysis and predictive modeling can be used in the context of student placements.

The system takes student-related inputs and uses a trained Machine Learning model to predict the placement outcome.

## ✨ Features

* 📊 Student placement prediction
* 🤖 Machine Learning-based prediction
* 🧹 Data preprocessing and preparation
* 📈 Model training and evaluation
* 🌐 Web-based interface
* ⚡ Fast prediction results
* 📁 Dataset-based analysis

## 📊 Dataset

The project uses student-related data containing academic and relevant placement attributes.

The dataset is processed before training the Machine Learning model to prepare it for prediction.

## 🤖 Machine Learning

The Machine Learning pipeline includes:

1. Data preprocessing
2. Feature preparation
3. Train-test split
4. Model training
5. Model evaluation
6. Prediction

The model achieved approximately **92.9% test accuracy** on the project dataset.

> Accuracy may vary depending on preprocessing, dataset changes, and model configuration.

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/mukeshyadav561420m-droid/Student-Placement-Prediction.git
```

### 2. Navigate to the project

```bash
cd Student-Placement-Prediction
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows:**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python run.py
```

Then open the local URL shown in the terminal.
